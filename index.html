Sistem dividen simulator
  • Selang-seling: dividen cair menambah kas untuk beli saham sesuai giliran bulan itu.
  • Custom lot: dividen membantu mencapai target lot bulanan. Jika reinvest ON, sisa dividen setelah target akan membeli lot tambahan.
  • Jika Program 2 tersambung, simulator memakai custom lot dari Program 2. Dividen manual Program 2 tidak dikirim agar tidak dobel hitung.
Target lot per bulan Seluruh setoran bulanan dipakai untuk target lot dulu, lalu sisa kas masuk RDPU. Jika kas bulan itu tidak cukup, simulator hanya membeli lot yang terjangkau.
